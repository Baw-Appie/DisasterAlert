# 프로젝트 헌장 및 목표·범위 합의 (PROJECT_CHARTER)

본 문서는 팀 **undefined (2인)**이 프로젝트 착수 단계에서 **주제 해석('전례 없는')**, **목표와 개발 범위(MVP)**, **필터링 정책**, **마일스톤**을 명확히 합의하기 위한 기준 문서입니다.

---

## 1. 주제 해석: '전례 없는 (Unprecedented)' 정의

> **평가 핵심**: 무엇이 '본 적 없는' 것인지 팀이 직접 **한 문장**으로 정의해야 하며, 그 정의와 실제 구현된 기능이 얼마나 설득력 있게 맞아떨어지는지를 중점적으로 검증합니다.

### 1.1 팀 undefined의 한 문장 정의 (초안)
- *"국가 단위로 일방향 발송되던 재난문자를 개인·가족의 생활권과 키워드 선택권을 결합해 '내가 직접 수신 범위를 설계하는 맞춤형 안전 큐레이션'으로 재정의한 서비스"*

*(팀 논의 후 표현 다듬기 가능)*

### 1.2 정의와 기능의 연결성 검증
| 핵심 가치 | DisasterAlert 구현 기능 | 사용자 경험 변화 |
| :--- | :--- | :--- |
| **생활권 확장과 선택** | 다중 관심 지역 설정 (내 거주지 + 가족 거주지) + 현재 위치 연동 | 나와 무관한 타 지역 알림 피로도는 줄이고, 멀리 사는 가족 지역의 위기 상황은 즉시 파악 |
| **사용자 중심 정보 선별** | 포함·제외 키워드 필터링 (**동시 매칭 시 포함 우선**) + **위급재난 예외 여부 사용자 선택 옵션** | 불필요한 반복 문자는 걸러내되 관심 주제는 놓치지 않으며, 위급재난 예외 기준까지 스스로 결정 |
| **휘발되지 않는 안전 정보** | 날짜·지역·재난 종류(태풍·호우·화재 등)·단어 복합 검색 | 지나가 버린 알림이나 놓친 재난문자를 언제든 조건별로 재탐색 |

## 2. 핵심 도메인 정책 합의

코드 구현 시 혼선이 없도록 다음 필터링 규칙을 단일 기준으로 확정합니다.

1. **포함 키워드와 제외 키워드 충돌 시 → `포함 키워드 우선`**
   - 재난문자 본문에 사용자의 **포함 키워드**와 **제외 키워드**가 동시에 들어 있는 경우, 중요 관심 정보를 놓치지 않도록 **포함 키워드를 우선 적용하여 목록에 표시**합니다.
2. **위급재난 필터 예외 여부 → `사용자에게 선택 옵션 제공`**
   - 위급재난 문자를 지역/제외 키워드 필터와 무관하게 항상 표시할지 여부는 서비스가 강제하지 않고, 설정 화면에서 **사용자가 직접 선택(On/Off 토글)**할 수 있도록 제공합니다.

## 3. 목표와 범위 합의 (MVP vs 추후 제공 범위)

2인 팀의 개발 리소스를 핵심 완성도에 집중하기 위해 **꼭 만들 것(MVP, P0)**, **여유 시 고도화(P1)**, **추후 제공(Post-MVP)**을 명확히 분리합니다.

### P0: 필수 구현 범위 (MVP — 반드시 완성하고 검증할 핵심 기능)
- [ ] **Node.js 백엔드 서버 구축 및 데이터 연동**
  - **재난안전데이터 공유 플랫폼**으로부터 재난문자 데이터 수집·파싱(발송 일시, 대상 지역, 재난 종류, 긴급 등급, 본문 정제)
  - iOS 클라이언트를 위한 목록 조회 및 다조건 검색 API 제공
- [ ] **맞춤 필터 설정 화면 및 필터링 엔진 (iOS SwiftUI)**
  - 관심 지역 다중 선택 및 저장 (내 거주지, 가족 거주지 등)
  - 포함 키워드 등록/삭제 및 제외 키워드 등록/삭제 (**동시 매칭 시 포함 키워드 우선 동작**)
  - 위급재난 예외 표시 여부 **사용자 선택 토글(On/Off)** 제공
  - 설정된 조건에 맞는 내 맞춤 재난문자 피드 제공
- [ ] **현재 위치 기반 주변 재난문자 확인 (iOS SwiftUI)**
  - `CoreLocation` 위치 권한 연동 및 현재 행정구역 매핑
  - 현재 위치 주변 지역의 최근 재난문자 조회 (위치 권한 거부 시 안내 및 수동 지역 전환 UI 포함)
- [ ] **지나간 재난문자 통합 검색 (iOS SwiftUI + Node.js API)**
  - 날짜 범위 선택
  - 지역 선택
  - 재난 종류 선택 (태풍, 호우, 화재, 지진, 폭염/한파 등)
  - 자유 검색어(기억나는 단어) 기반 본문 검색
- [ ] **재난문자 상세 화면 (iOS SwiftUI)**
  - 목록에서 재난문자 선택 시 전문(상세 내용), 발송 일시, 재난 분류, 대상 지역 상세 표시

### P1: 여유 시 고도화 범위 (MVP 안정화 이후 선택 진행)
- [ ] **관심 지역 별칭(라벨) 지정**: 선택한 지역에 '우리 집', '부모님 댁', '학교/직장' 등 별칭 부여
- [ ] **재난문자 공유 및 북마크**: 가족에게 주요 재난문자 내용을 즉시 공유하거나 중요 문자를 보관하는 기능
- [ ] **최근 조회 캐싱**: 일시적 네트워크 지연 시 최근 확인한 맞춤 재난문자 목록 로컬 열람 지원

### Post-MVP: 추후 제공 기능 (이번 제출 범위 외 향후 로드맵)
- **실시간 푸시 알림 발송 (APNs 연동)**: 백그라운드 실시간 푸시 발송 및 푸시 알림 탭 딥링크 기능은 본 프로젝트의 추후 제공 로드맵으로 분류하며, 발표 시 향후 확장 구조로 소개합니다.
