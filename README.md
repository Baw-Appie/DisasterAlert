# DisasterAlert

> **"재난 정보를 더 많이 전달하는 것이 아니라, 각자가 필요한 정보를 알아보기 쉽게 전달합니다."**

**DisasterAlert**는 수많은 재난문자 속에서 내가 사는 곳, 가족이 있는 곳, 그리고 내가 관심을 두고 있는 상황에 맞춰 지금 나에게 꼭 필요한 재난 정보만 선별해 확인하고 검색할 수 있도록 돕는 **iOS 맞춤형 재난 정보 앱**입니다.

## 2. 기획 배경 및 핵심 기능

재난문자는 일상과 안전에 직결되는 중요한 정보이지만, 현재 나와 무관한 지역이나 반복적인 내용까지 무차별적으로 수신하다 보면 정작 주의 깊게 확인해야 할 알림을 놓치기 쉽습니다. **DisasterAlert**는 사용자가 수신 및 조회 범위를 스스로 설계할 수 있도록 다음 핵심 기능을 제공합니다.

1. **관심 지역 맞춤 설정**: 내 거주지뿐 아니라 가족이 거주하는 지역 등 여러 관심 지역을 직접 선택하여 확인
2. **포함·제외 키워드 필터링 및 안전 옵션**:
   - 집중해서 보고 싶은 주제(**포함 키워드**)와 반복해서 도착하는 불필요한 내용(**제외 키워드**) 설정
   - 한 재난문자에 포함 키워드와 제외 키워드가 동시에 들어 있을 경우 **포함 키워드를 우선 적용**하여 중요 정보를 놓치지 않도록 처리
   - 위급재난 문자의 필터 예외(항상 표시) 여부 역시 **사용자가 직접 선택(On/Off)**할 수 있도록 옵션 제공
3. **현재 위치 기반 주변 재난문자 조회**: 기기 현재 위치를 기준으로 주변 지역의 재난문자를 즉시 확인
4. **지나간 재난문자 통합 검색**: 날짜, 지역, 재난 종류(태풍, 호우, 화재 등), 기억나는 단어로 과거 이력 재확인
5. **재난문자 상세 확인**: 목록에서 항목 선택 시 재난문자 전문(상세 내용), 발송 시각, 재난 유형 및 대상 지역 확인
   *(※ 실시간 푸시 알림 발송 기능은 추후 확장 기능으로 제공 예정)*

## 3. 기술 스택 및 아키텍처 요약

| 구분 | 사용 기술 및 도구 |
| :--- | :--- |
| **iOS 클라이언트** | **Swift, SwiftUI** (`CoreLocation` 기반 현재 위치 연동) |
| **백엔드 서버** | **Node.js** (재난안전데이터 공유 플랫폼 데이터 수집·정제 및 REST API 제공) |
| **데이터 소스** | **재난안전데이터 공유 플랫폼** (재난문자 발령 현황 데이터) |
| **코드 품질 / 린터** | **SwiftLint** (iOS 정적 분석 및 컨벤션 강제) |
| **AI 활용 및 표준 기술** | AI 코딩 에이전트, **`ios-simulator-skill`** (iOS 시뮬레이터 빌드·실행 및 UI 동작 검증) |

## 5. 로컬 실행 가이드

> **채점 기준 준수 사항**: 외부 평가자가 `README.md`만 보고도 프로젝트를 바로 실행할 수 있도록 초기 보일러플레이트 구성 직후 실제 명령어와 환경 변수 예시를 상세히 유지합니다.

### 5.1 저장소 클론 및 Node.js 서버 실행 (`server/`)
```bash
git clone https://github.com/Baw-Appie/DisasterAlert.git
cd DisasterAlert/server
cp .env.example .env   # 재난안전데이터 공유 플랫폼 API 인증키 설정
npm install
npm run dev
```

### 5.2 iOS 앱 실행 (`ios/`)
1. Xcode에서 `ios/DisasterAlert.xcodeproj` (또는 `.xcworkspace`) 열기
2. 로컬 서버 주소 설정 확인 후 iOS Simulator 선택 및 실행 (`Cmd + R`)
3. 린트 검사:
   ```bash
   cd ios && swiftlint
   ```
